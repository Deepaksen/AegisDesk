# Software Installation Policy

## Approved software catalogue
Employees install software only from the Self Service catalogue on their laptop. Catalogue software is pre-approved and installs without administrator rights.

## Software that is not in the catalogue
Request it through AegisDesk with a business justification. Non-catalogue software requires manager approval and a security review, which takes up to 5 business days. Open-source software additionally needs a licence check by the Legal team.

## Administrator rights
Employees do not receive local administrator rights. Developers who need elevated rights for specific tasks use the "Admin by Request" tool, which grants 30 minutes of elevation and is logged.

## Prohibited software
The following are never allowed: peer-to-peer or torrent clients, personal cloud-sync clients (for example personal Dropbox), remote-control tools not provided by IT, and cracked or unlicensed software.
