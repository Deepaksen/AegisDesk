# Privileged Access Policy

## What counts as privileged access
Privileged access means administrator rights on servers, databases, cloud accounts or security tools, and any role that can change other people's access.

## Just-in-time access
Privileged access is never permanent. It is granted just in time for a maximum of 8 hours per request, through the PAM vault. Every privileged session is recorded.

## Approvals
Each privileged access request needs approval from the requester's manager and from the Security team. Approvals are recorded in AegisDesk. Requests without a linked change or incident ticket are rejected.

## Shared and break-glass accounts
Shared administrator accounts are not allowed. Break-glass accounts exist for emergencies only; using one requires approval from the IT Service Manager and triggers an automatic security review within 24 hours.
